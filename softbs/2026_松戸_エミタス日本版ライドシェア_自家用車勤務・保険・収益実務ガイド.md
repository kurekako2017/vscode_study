# 松戸でエミタスの日本版ライドシェアを始めるための実務参考ガイド
## ― 自家用車・勤務条件・営業範囲・収入・保険確認事項まとめ ―

更新日：2026年8月28日  
対象：松戸駅周辺から、三ツ矢エミタスタクシーHDの「日本版ライドシェア（自家用車活用事業）」で、自家用車を使って副業を始める場合

---

## 1. 先に結論

松戸・柏エリアでは、三ツ矢エミタスタクシーHDが日本版ライドシェアドライバーを募集しており、**普通一種免許で応募可能、マイカー利用可能、短時間勤務可能**です。

ただし、実際にマイカーで始める前に一番重要なのは**自動車保険の確認**です。

現在加入しているSBI損保の個人向け自動車保険は、SBI公式上、**「有償で人または貨物を運送する車両」は引受対象外**とされています。そのため、「使用目的を業務使用に変えるだけ」でライドシェア対応になるとは考えない方が安全です。

一方、日本版ライドシェアはタクシー会社の管理下で行う制度なので、営業中の事故については事業者側の保険・補償が関係します。

しかし、2026年8月28日時点で確認できたエミタス公式の採用ページ・求人・ブログには、次の点について**具体的な補償額・免責額まで公開した資料は見つかりませんでした**。

- マイカー本人の車両損害
- 車両保険の免責額
- 配車待機中の補償
- 迎車中の補償
- 乗客降車後の回送中の補償
- 事故時に個人保険と会社保険のどちらを先に使うのか

したがって、**SBIを解約したり他社へ変更する前に、まずエミタスから実際の保険内容を確認する**のが正しい順序です。

---

# 2. 日本版ライドシェアとは

日本版ライドシェアの正式な制度名は、

**自家用車活用事業**

です。

一般のUberのように個人が自由に有償運送する制度ではなく、

- タクシー会社が管理
- 一般ドライバーを雇用
- 自家用車等を利用
- 国が認めた地域・曜日・時間帯で運行

する制度です。

国土交通省は、2024年3月にこの制度を創設しています。

---

# 3. 二種免許は必要か

## 結論

**エミタスの日本版ライドシェアなら普通一種免許で応募可能です。**

通常のタクシードライバーは普通二種免許が必要ですが、日本版ライドシェアは一般ドライバーを活用する仕組みなので、二種免許は不要です。

エミタス公式の採用条件：

- 普通免許取得後1年以上
- 70歳未満
- 直近2年間に重大事故なし
- 直近2年間に免停処分等なし

# 4. 松戸でのエミタス募集

エミタスは公式に、

**柏市・松戸市のライドシェアドライバー**

を募集しています。

特徴：

- 普通免許でOK
- マイカーOK
- 会社保有車両も利用可能
- 短時間勤務OK
- 私服OK
- 未経験可
- 研修あり
- ノルマなし

松戸から自家用車で副業したい場合、現在確認できる候補として相性が良い会社です。

# 6. 勤務時間

東葛エリア（松戸・柏など）のエミタス公式採用条件は、

**金曜日・土曜日 16:00 ～ 翌朝6:00**

です。

この14時間を全部働くという意味ではありません。

エミタスは短時間勤務可能としており、パート・アルバイト雇用です。

基本的には、

**週20時間未満**

です。

本業が正社員でも、エミタスは条件付きで応募可能としています。

正社員の場合：

- マイカー利用限定
- 本業の月間残業時間＋ライドシェア勤務時間が60時間未満

という独自条件が公表されています。

# 7. 営業範囲

松戸は「東葛交通圏」に属します。

主な区域：

- 松戸市
- 柏市
- 流山市
- 野田市
- 我孫子市

日本版ライドシェアは、営業区域・曜日・時間が限定されています。

したがって、

**東京へ自由に移動して、東京の中だけでUberのように営業することはできません。**

---

# 8. 東京方面へ乗客を送れるか

営業区域内から区域外へ乗客を送るケースはあり得ます。

例えば、

- 松戸 → 柏：○
- 松戸 → 流山：○
- 松戸 → 我孫子：○
- 松戸 → 東京：制度上あり得る

一方、

- 東京 → 東京

のように東葛交通圏と関係のない運送を、東葛所属の車両が自由に営業することはできません。

---

# 9. 東京へ送った後の「回程」は特に確認が必要

制度上の営業区域ルールと、GOアプリ・エミタス内部の配車ロジックは別問題です。

例えば、

松戸 → 上野

まで乗客を送った後、

上野 → 松戸  
上野 → 柏

のような「東葛へ戻る客」を受けられる可能性があれば、空車回送が減るため非常に有利です。

しかし、2026年8月28日時点で確認したエミタスの公開資料には、

**「東京都内から東葛へ戻る回程配車を必ず受けられる」**

という明確な記載はありませんでした。

これは応募時に必ず確認した方が良い項目です。

# 12. 現在のSBI損保について

現在加入している保険会社は、

**SBI損害保険株式会社**

です。

保険証券上、契約車両や走行距離等の情報が確認できます。

しかしSBI損保公式FAQでは、

**「有償で人または貨物を運送することがある車両の契約は引き受けできない」**

と明記されています。

そのため、

「日常・レジャー」  
↓  
「業務使用」

へ変更すればライドシェアOK、という単純な話ではありません。

ライドシェアは「有償で人を運送する」行為だからです。

# 13. SBIを今すぐ解約してはいけない理由

現時点では、

**SBIを先に解約する必要はありません。**

まず確認するべきなのは、

**エミタスがライドシェア運行中にどこまで保険を掛けているか**

です。

もし会社側保険がライドシェア業務中を完全にカバーし、SBIが私用時間だけの契約継続を認めるなら、

### 私用時
SBI損保

### ライドシェア業務時
エミタス側の事業者保険

という分担が成立する可能性があります。

ただし、この併存をSBIが認めるかどうかは、SBIに個別確認が必要です。

# 16. 国の制度上の保険

日本版ライドシェアはタクシー事業者の管理下で実施されます。

事業者には損害賠償能力を確保することが求められ、許可関係資料には対人・対物保険についての申告があります。

ただし国の制度上必要な賠償責任保険があっても、

**ドライバー所有のマイカーそのものの修理費まで必ず全額補償するとは限りません。**

ここを混同しないことが重要です。

---

# 17. 一番重要：マイカー車両保険

例えば自分の車で、

- ガードレールに衝突
- 柱に擦る
- 縁石に乗り上げる
- 駐車場で事故
- 当て逃げ
- 相手に過失がない単独事故

を起こした場合、

対人・対物賠償保険だけでは自分の車は直せません。

エミタス側保険に「車両補償」がなければ、

**修理代を自分で払う可能性があります。**

そのため、応募前に最優先で確認します。

3. 配車待機・迎車・回送も対象か

5. 保険内容を書面でもらえるか

>
> また、ライドシェアへの登録自体が御社の引受条件上問題になるか教えてください。

「仕事で使います」だけではなく、

**自家用車活用事業（日本版ライドシェア）で有償旅客運送をする**

と明確に説明します。

# 20. SBIが継続不可と言った場合

この場合は初めて、他社保険を探します。

順序：

1. エミタス側の保険内容を取得
2. SBIへ確認
3. SBI継続不可の場合だけ他社へ見積もり
4. 日本版ライドシェア利用であることを明記
5. 保険開始日を確定
6. 新保険開始を確認
7. その後SBI解約

**新しい保険が成立する前にSBIを先に解約しないこと。**

無保険期間を作らないようにします。

---

# 21. 他社保険を探す場合の言い方

代理店には、

> 自家用車活用事業（日本版ライドシェア）で使用する自家用乗用車です。  
> タクシー会社に雇用され、事業者の運行管理下で有償旅客運送を行います。  
> 私用とライドシェアの両方をカバーできる契約、または事業者保険と併存できる契約を探しています。

と伝えます。

単に、

「業務使用です」

では不十分です。

# 25. 収益判断のポイント

この副業をやるかどうかは、「時給」だけで判断しない方が良いです。

重要なのは、

**実質利益 ＝ 受取報酬 － ガソリン － 車両消耗 － 空車回送 － 保険増額分**

です。

特に松戸は東京に近いため、

**東京方面への長距離客を乗せた後、空車で戻る割合**

が収益に大きく影響します。

そのため、

「東京都内から東葛へ戻る配車を受けられるか」

は、保険確認と同じくらい重要です。
