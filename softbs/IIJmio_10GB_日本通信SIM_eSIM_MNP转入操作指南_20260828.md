# IIJmio 10GB → 日本通信SIM eSIM MNP 转入操作指南

> 目标：先把目前 IIJmio 的电话号码通过 MNP
> 转入日本通信SIM，继续使用原电话号码，并使用 eSIM。

## 1. 最终要做什么

当前：

**IIJmio 音声 eSIM（10GB、无免费通话）**

转为：

**日本通信SIM eSIM（保留原电话号码）**

这里需要注意：

-   电话号码可以通过 **MNP** 保留下来。
-   IIJmio 的 eSIM 本身不能直接变成日本通信 eSIM。
-   转入后，需要在手机中安装日本通信重新发行的 eSIM。
-   不要提前手动解约 IIJmio。
-   MNP 正常完成后，原 IIJmio 对应线路会随转出而结束。

## 3. 最重要的时间安排

IIJmio MNP 转出月份的基本费用需要特别注意月末时间。

为了避免跨到下个月才完成 MNP，建议：

**目标：8月30日白天开始办理，并尽量在8月31日前完成。**

不建议：

**8月31日晚上才开始操作。**

原因是身份确认、MNP One Stop 或 eSIM 发行如果发生延迟，可能跨到9月。

建议安排：

### 8月28～29日

只做准备工作：

-   下载日本通信 App
-   确认 My Number Card
-   确认 My Number Card 密码
-   确认信用卡
-   确认 IIJmio 登录账号/密码
-   确认手机连接 Wi-Fi
-   不要删除 IIJmio eSIM
-   不要解约 IIJmio

### 8月30日白天

正式进行：

**日本通信 App → 新申请 → MNP → IIJmio → eSIM**

完成身份认证和 MNP One Stop。

### 8月30～31日

日本通信审核/发行完成后：

1.  完成 MNP 切换
2.  安装日本通信 eSIM
3.  设置移动网络
4.  测试电话
5.  测试短信
6.  测试 4G/5G 数据通信
7.  全部正常后，再处理手机中旧的 IIJmio eSIM

## 4. 申请前准备

建议提前准备：

### 手机

日本版 OPPO Reno11 A。

需要：

-   Wi-Fi
-   NFC
-   eSIM 功能
-   保持足够电量

### My Number Card

准备：

-   マイナンバーカード
-   4位数字密码
-   署名用電子証明書密码（需要时使用）

### 支付

准备本人名义可使用的信用卡。

### IIJmio

提前确认：

-   IIJmio 登录账号
-   登录密码
-   当前电话号码

因为 MNP One Stop 过程中可能跳转到 IIJmio 页面登录确认。

优先使用：

**MNPワンストップ**

流程大致为：

日本通信 App\
↓\
选择「他社から乗り換え（MNP）」\
↓\
选择 IIJmio\
↓\
跳转 IIJmio\
↓\
登录 IIJmio\
↓\
确认转出\
↓\
返回日本通信继续申请

这种情况下，通常**不用提前取得 MNP予約番号**。

如果实际申请画面提示不能使用 One Stop，再按照画面要求取得
MNP予約番号即可。

## 7. 套餐选择

如果选择「合理的みんなのプラン」，申请时注意通话选项。

可根据实际使用方式选择：

### 方案A：月70分钟免费

适合：

-   一个月电话次数不一定很多
-   偶尔会打一通10～20分钟电话
-   希望总通话时间在70分钟内灵活使用

### 方案B：每次5分钟以内免费

适合：

-   经常打短电话
-   每次基本1～5分钟
-   每月电话次数较多

如果平时偶尔会打较长电话，优先考虑 **70分钟/月**。

## 8. eSIM需要重新设置

需要。

正确理解是：

**IIJmio eSIM ≠ 日本通信 eSIM**

MNP只负责把：

**电话号码**

从 IIJmio 转移到日本通信。

转入完成后，日本通信会发行自己的 eSIM，需要重新安装。

因此不要认为原来的 IIJmio eSIM 会自动变成日本通信。

## 10. 绝对不要提前做的事情

### 不要提前解约 IIJmio

你需要的是：

**MNP转出**

而不是：

**先解约 → 再申请日本通信**

否则可能导致原电话号码无法正常通过 MNP 保留。

### 不要提前删除 IIJmio eSIM

在日本通信完全开通以前，先保留原 eSIM。

### 不要等月底最后几个小时才申请

月底办理最大的风险不是操作本身，而是：

-   本人确认延迟
-   MNP One Stop 延迟
-   系统维护
-   eSIM 发行延迟
-   自己操作中出现问题

所以给自己至少留一天余量。

## 11. 开通后的检查清单

日本通信 eSIM 安装完成以后逐项确认：

-   [ ] 手机显示日本通信/NTT DOCOMO 网络
-   [ ] 可以拨出电话
-   [ ] 可以接听电话
-   [ ] 原来的电话号码没有变化
-   [ ] 可以发送 SMS
-   [ ] 可以接收 SMS
-   [ ] 关闭 Wi-Fi 后可以使用移动数据
-   [ ] 4G/5G 正常
-   [ ] 日本通信 App/マイページ可以查看契约
-   [ ] 套餐正确
-   [ ] 通话选项正确
-   [ ] IIJmio MNP 转出状态正常

全部确认后，本次 MNP 基本完成。

目前计划是：

**IIJmio 原号码 → 日本通信 eSIM（MNP）**

先确保这一条完全正常。

**新规申请第二个电话号码**

eSIM、号码或默认移动数据线路的风险。
