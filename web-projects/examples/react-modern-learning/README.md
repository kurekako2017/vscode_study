# React Modern Learning V1.1

企业导学版。

这是一个面向企业开发学习的 React 项目。

它的目标不是只教你“React 怎么写”，而是帮助你理解 React 在企业系统中的位置。

## 为什么学习 React

React 不是为了单纯写页面，而是为了掌握企业前端常用能力：

- 组件化
- 状态管理
- 路由组织
- 前后端协作
- 自动化测试

## 安装

```bash
npm install
```

## 启动

```bash
npm run dev
```

## 学习路线

推荐按下面顺序学习：

1. `Home`
2. `Hooks`
3. `Router`
4. `Context`
5. `API`
6. `Test`
7. `Learning Trace`
8. `Retail Insight AI`
