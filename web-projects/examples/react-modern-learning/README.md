# React Modern Learning

一个用于学习 React 架构、路由、Hook、状态流和测试配对的练习项目。

## 安装

```bash
npm install
```

## 启动

```bash
npm run dev
```

## 学习顺序

1. `Home`
2. `Hooks`
3. `Router`
4. `Context`
5. `API`
6. `Test`

## Learning Trace

页面右侧的 `Learning Panel` 默认开启，打开页面就能看到 Trace、Component Tree、Source Files 和 Test File。
