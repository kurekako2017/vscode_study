# 项目组原始事前学习要求｜整理存档

本文件根据用户提供的《Databricks 参画前の事前学習内容》整理，作为本套教程的验收基准。

## 项目组要求的重点

### 1. Databricks 基本概念

- Databricks 概要
- Workspace
- Catalog / Schema / Table
- Data Lake / Lakehouse
- SQL Warehouse / Compute

目标：

> 理解 Databricks 上如何管理和处理数据。

### 2. Notebook【重点】

- 创建 / 编辑
- Cell 创建 / 执行
- SQL / Python / PySpark
- Table 查询
- 执行结果
- Notebook 保存 / 管理
- 简单数据加工

### 3. Databricks SQL【重点】

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOIN
- CASE WHEN
- Subquery
- CTE
- INSERT
- UPDATE
- MERGE
- CREATE TABLE / VIEW
- Table / View / Temporary View 基本区别

### 4. Bronze / Silver / Gold【重点】

- Bronze：元数据 / 取り込み直後
- Silver：清洗 / 加工
- Gold：业务 / 分析用途

### 5. Spark / PySpark 基础

目标仅为：

- 知道 Spark 是什么；
- 知道 Databricks 与 Spark 的关系；
- 知道 PySpark；
- 知道 DataFrame；
- 能看懂简单抽取 / 加工。

低优先级：

- RDD
- Shuffle
- Partition 深入
- Catalyst Optimizer
- Spark 内部结构

### 6. 实际操作

至少：

1. Notebook
2. SQL
3. Table 查询
4. JOIN
5. Table / View
6. Python / PySpark
7. Bronze → Silver → Gold
