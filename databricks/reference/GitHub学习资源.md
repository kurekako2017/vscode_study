## 学习原则

```text

  ↓

  ↓
遇到需要补充的知识
  ↓
再使用 GitHub 示例
```

不要：

```text
仓库 A 看一点
+
仓库 B 看一点
+
仓库 C 看一点
→ 主线丢失
```
