## 设计原则

- FastAPI：HTTP 边界
- TaskService：业务用例层
- LangGraph：Workflow 状态机
- LangChain：RAG 编排、Retriever、Prompt、Tool
- Repository：存储抽象
- SQLite：当前实现
- PostgreSQL + pgvector：企业目标
