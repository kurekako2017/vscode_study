## 15. 最短记忆版

### 15.1 一张图记住 ERIP

```text
フロントエンド（React）
  → バックエンド API 境界（FastAPI）
  → 認証 / 認可（JWT / RBAC）
  → サービス層
  → AI コンポーネント（LangChain）
  → ステートフル・エージェントワークフロー（LangGraph）
  → LLM ゲートウェイ
  → リポジトリ層 / PostgreSQL / pgvector
  → 承認 / 監査
```

### 15.2 30 秒核心句

```text
LangChain は、
プロンプト、リトリーバー、RAG コンテキスト、
引用情報、ツール、LLM 連携などの
AI コンポーネントを構成するフレームワークです。

LangGraph は、
ステート、ノード、エッジ、条件分岐を用いて、
多段階のエージェントワークフローを制御する
フレームワークです。

ERIP では、
LangChain で各 AI 処理を構成し、
LangGraph で全体ワークフローを制御しています。
```

### 15.3 易混对

| A | B | 区别一句话 |
|---|---|---|
| 認証 | 認可 | 誰か / 何をしてよいか |
| LangChain | LangGraph | AI コンポーネント / ワークフロー制御 |
| 生成完了 | 承認完了 | 自動処理終了 / 業務確定 |
| ステート | DB | 実行中状態 / 業務事実 |
| 引用情報 | 参照元 | 回答に付く根拠情報 / 情報の出どころ |
| 検索処理 | 生成 | 根拠を集める / 文章を作る |
| InMemory リポジトリ | PostgreSQL | テスト用 / 正式データ |
