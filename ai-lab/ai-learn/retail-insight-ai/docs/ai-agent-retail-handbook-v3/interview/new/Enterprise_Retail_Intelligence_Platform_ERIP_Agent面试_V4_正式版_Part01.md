# Chapter 1　ERIPとは

## 1.1 ERIPとは何ですか

### 面试官可能的提问

```text
ERIPとは何ですか。

どのようなシステムですか。
```

### 推荐回答

```text
ERIP、
Enterprise Retail Intelligence Platformは、
大手流通グループ向けの
AI経営分析プラットフォームです。

経営企画部門が保有する社内文書を一元管理し、
RAG検索によって分析根拠を取得し、
AIが経営分析を実施します。

その結果を取締役会向けレポートとして生成し、
承認、監査までを
一つの業務フローとして実現した
企業向けAIシステムです。
```

### 回答重点

第一句话先说明：

- 面向谁
- 是什么系统
- 解决什么业务

不要一开始先讲 FastAPI、React、Docker。

## 1.2 なぜERIPを開発したのですか

### 推荐回答

```text
従来の経営分析では、
担当者が売上データ、在庫データ、
会議資料、Excel資料などを個別に確認し、
分析レポートを作成していました。

資料が複数の場所に分散しているため、
情報収集だけでも多くの時間が必要でした。

また、
分析結果の根拠を後から確認することも
容易ではありませんでした。

そこで、
社内文書を一元管理し、
RAG検索によって分析根拠を取得し、
AIが分析を行い、
最終的なレポート作成までを効率化するために、
ERIPを開発しました。
```

### 追问：何が一番改善されましたか

```text
資料検索、分析、レポート作成までの時間を
大幅に短縮できた点です。

また、
分析結果の根拠となる社内文書も
同時に提示できるため、
説明責任を担保できる点も
大きな改善点です。
```

---

## 1.3 誰が利用するシステムですか

### 推荐回答

```text
主な利用者は経営企画部門です。

その他、
店舗運営部門、商品企画部門、
マネージャー、承認者、
監査担当者も利用します。
```

### 追问：一般社員も使いますか

```text
利用できます。

ただし、
ロールによって利用可能な機能が異なります。

例えば、
管理者は承認や権限管理まで利用できますが、
一般利用者は文書検索や分析依頼が中心になります。
```

---

## 1.4 どのような課題を解決しましたか

### 推荐回答

```text
主に三つあります。

一つ目は、
社内文書が複数の場所に分散していることです。

二つ目は、
分析レポート作成に時間が掛かることです。

三つ目は、
分析結果の根拠が残りにくいことです。

ERIPでは、
文書管理、RAG検索、AI分析、
Approval、Auditまでを一元管理することで、
これらの課題を解決しました。
```

### 追问：一番大きい価値は何ですか

```text
AIが回答することだけではありません。

AIが社内文書を根拠として分析し、
利用者が分析結果と根拠文書を
同時に確認できることです。

この点が、
企業業務で利用する上で
最も重要な価値だと考えています。
```

---

## 1.5 なぜChatGPTだけでは不十分ですか

### 推荐回答

```text
ChatGPTは非常に優れた汎用生成AIですが、
企業内部文書を業務ルールに沿って
利用する仕組みは別途必要です。

また、
企業業務では、
回答の根拠、アクセス権限、
承認、監査、利用履歴管理も必要です。

ERIPでは、
社内文書を対象にRAG検索を実施し、
分析根拠、承認履歴、監査ログまで管理できます。

そのため、
企業業務向けのAIプラットフォームとして
ERIPを構築しました。
```

### 回答原则

不要说：

```text
ChatGPTは使えません。
```

应说明：

```text
ChatGPTは汎用AI、
ERIPは企業業務向けAIプラットフォームです。
```

## 1.6 ChatGPTとの違い

| 比较项目 | ChatGPT | ERIP |
|---|---|---|
| 主要用途 | 汎用対話・生成 | 企業経営分析 |
| 数据来源 | 一般知識・入力内容 | 社内文書 |
| 根据信息 | 必ずしも提示されない | RAG検索結果を提示 |
| 权限控制 | 业务系统侧需另行实现 | JWT / RBAC |
| 审批 | 标准对话功能中无业务审批 | Approval Workflow |
| 审计 | 需要另行构建 | Audit Log |
| 文档管理 | 不属于核心业务功能 | Enterprise Document Management |
| 报告生成 | 通用文本生成 | 取締役会向けレポート |

### 总结回答

```text
ChatGPTは汎用AIです。

ERIPは、
社内文書、権限、承認、監査を統合した
企業向けAIプラットフォームです。

用途と責任範囲が異なります。
```

## 1.7 なぜRAGを採用しましたか

### 推荐回答

```text
LLMだけでは、
企業内部の最新文書や
業務固有情報を正確に利用できません。

そこで、
RAG検索によって関連文書を取得し、
その内容をLLMへ渡して
分析を実施する構成にしました。

これにより、
回答品質と根拠提示の両方を実現しています。
```

### 追问：RAGだけで十分ですか

```text
いいえ。

RAGは、
関連文書を検索して取得する仕組みです。

実際の分析、
レポート生成、
承認、
監査などは、
別の業務機能として実装しています。
```

## 1.10 ERIP 三分钟说明

```text
ERIPは、
大手流通グループの経営企画部門向けに構築した
AI経営分析プラットフォームです。

従来は、
売上資料、在庫資料、会議資料、Excelなどを
担当者が個別に確認し、
手作業で経営分析レポートを作成していました。

ERIPでは、
これらの社内文書を一元管理し、
RAG検索によって質問や分析テーマに関連する

取得した文書を利用して、
AIが売上、在庫、地域差、商品傾向などを分析し、

また、
誰が文書を登録し、
誰が分析を実行し、

FastAPI、React、PostgreSQL、
JWT/RBAC、Repository、
RAG、AI Workflowを中心に
設計・実装を担当しました。
```

## 1.11 ERIP 五分钟说明

```text
ERIP、
Enterprise Retail Intelligence Platformは、
大手流通グループ向けの
AI経営分析プラットフォームです。

主な利用者は、
経営企画部門、店舗運営部門、
マネージャー、承認者、監査担当者です。

従来の経営分析では、
売上データ、在庫データ、会議資料、
Excel資料などが複数の場所に分散し、
担当者が個別に情報を収集していました。

そのため、
分析開始前の資料確認に時間が掛かり、
完成した分析結果についても、
どの文書を根拠に判断したのかを
後から説明しにくい課題がありました。

ERIPでは、
最初に社内文書を登録し、
文書を検索可能な単位へ分割します。

利用者が分析テーマや質問を入力すると、
RAG検索によって関連する文書を取得します。

取得した根拠文書をAI Workflowへ渡し、
売上傾向、在庫状況、地域差、
商品別の課題などを分析します。

分析結果は、
取締役会向けレポートとして生成されます。

ただし、
AIが生成した内容をそのまま確定するのではなく、
Approval Workflowによって
担当者または管理者が確認・承認します。

また、
文書登録、検索、分析、承認、
権限操作などの履歴をAudit Logへ保存し、
誰が、いつ、何を行ったかを確認できます。

認証・認可にはJWTとRBACを採用し、
ロールごとに利用できる機能を制御しています。

バックエンドはFastAPI、
フロントエンドはReact、
データベースはPostgreSQLを採用しています。

私は、
API設計、画面開発、データ設計、
Repository、JWT/RBAC、
RAG、AI Workflow、
Approval、Auditの設計・実装を担当しました。
```
