### 真实业务主链（当前）

```text
登录/JWT/RBAC
→ 文書管理 Upload / Import / Chunk
→ RAG 检索 / Citation（默认 keyword；默认可不调真实 LLM Provider）
→ 显式 AI 分析（low_cost · LLM Gateway）
→ 取締役会报告（high_quality · LLM Gateway）
→ Report / ReportVersion
→ Approval（pending → approve/reject · History · ownership）
→ Persistent Audit
→ LLM Usage Ledger
```

### 部署（当前，两种并列）

```text
本地完整开发（业务可测）：
  宿主 PostgreSQL + FastAPI + Vite  → 页面 :5173
  脚本：scripts/start_local.sh
  ※ 单独只启动 Vite 不能完成业务测试

Docker Compose（可选部署 / 企业验收演示）：
  PostgreSQL+pgvector + Backend + Nginx Frontend → 页面 :8080
  脚本：scripts/compose_up.sh
  Volume：erip_postgres_data
```

### 测试适配器（非业务运行）

```text
InMemory Repository = unittest / test isolation adapter only
  - 不作页面正式数据源
  - 不作企业验收权威
  - 不替代 PostgreSQL
```

## 框架关系（当前）

```text
React
  ↓
FastAPI（HTTP Boundary · JWT/RBAC）
  ↓
Service（Document / RAG / AI / Approval / Audit / Runtime）
  ↓
LLMGateway（仅显式 AI / 董事会报告；默认 stub）
  ↓
Repository Interface
  ↓
PostgreSQL + pgvector（Current / 正式）

辅线（可选讲解）：
  Task API → TaskService → LangGraph Workflow → KPI / Research → SSE
```

## 设计原则（V1.0）

| 层 | 原则 |
|---|---|
| FastAPI | HTTP 边界、DI、校验；不直连 LLM SDK |
| Service | 业务用例与状态机 |
| LLM Gateway | 收费 side-effect 唯一入口 |
| Repository | 隐藏 Postgres / InMemory |
| PostgreSQL + pgvector | **正式权威存储** |
| InMemory | unittest / test isolation adapter |
| Docker Compose | 可选部署与验收，不是唯一开发方式 |
