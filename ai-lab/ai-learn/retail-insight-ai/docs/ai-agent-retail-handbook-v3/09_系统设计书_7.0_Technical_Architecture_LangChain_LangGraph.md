# 7.0 技术架构（ERIP V1.0 当前）

## 整体技术架构（当前主图）

```text
                                      Browser
                                         │
                    React Frontend（Vite 5173 / Nginx 8080）
                    JWT sessionStorage · ProtectedRoute · RBAC UI
                                         │
                          REST /api/v1 · /api/tasks · /health
                                         │
                               FastAPI（Uvicorn）
                    JWT 校验 · require_permission · request_id
                                         │
                                  Service Layer
          ┌──────────────────────────────┼──────────────────────────────┐
          │                              │                              │
          ▼                              ▼                              ▼
 Document Services            RAG / AI Component Layer          Agent Workflow Layer
 Upload · Import · Chunk       LangChain                         LangGraph
                               Prompt · Retriever                State · Node · Edge
                               Context · Citation                Route · KPI · Research · Report
          │                              │                              │
          │                              └──────────────┬───────────────┘
          │                                             ▼
          │                                  LLM Gateway（唯一外呼）
          │                                  low_cost / high_quality
          │                                  Evidence · Idempotency · Ledger
          │                                             │

                                  ▼
                       Analysis / Executive Report
                                  │
                    ┌─────────────┴─────────────┐
                    ▼                           ▼
             ApprovalService          PersistentAuditService
          ReportVersion · History       Audit append-only
                    │                           │
                    └─────────────┬─────────────┘
                                  ▼
                    Repository Pattern（interface）
                                  │
                                  ▼
              PostgreSQL + pgvector（Current / 正式 Repository）
              documents.content · chunks · approvals · audit_logs
              llm_usage_ledger · ai_runtime_settings · report_versions
```

> **架构阅读重点：**
>
> - **LangChain**：负责 LLM、Prompt、Retriever、RAG Context、Citation 等 AI 处理组件的组合。
> - **LangGraph**：负责将分析步骤组织为带 State 的 Node / Edge 工作流，并控制路由、分支与执行顺序。
> - 两者不是替代关系：**LangChain 提供 AI 组件，LangGraph 负责有状态工作流编排。**
> - 当前源码中 LangGraph 已用于 Task / KPI Workflow；LangChain 的业务集成范围必须以实际 import 与调用链为准，不得仅因依赖树存在就夸大为全主链已落地。

## AI Agent 核心框架（LangChain / LangGraph）

### 框架职责

| 框架 | ERIP 中的架构职责 | 面试口径 |
|---|---|---|
| **LangChain** | 组织 LLM、Prompt、Retriever、RAG Context、Citation 等 AI 组件 | **AI 组件层** |
| **LangGraph** | 使用 State、Node、Edge、条件分支组织多阶段分析流程 | **Agent Workflow 编排层** |

### 协作关系

```text
用户问题 / 分析任务
        │
        ▼
FastAPI / Service
        │
        ▼
LangGraph Workflow
  route → kpi / research → report
        │
        ├── Node 内调用 LangChain Retriever / Prompt / LLM
        │
        ▼
LLM Gateway
        │
        ▼
Report → Approval → Audit
```

### LangChain 与 LangGraph 的区别

```text
LangChain
= LLM / Prompt / Retriever / Tool 等 AI 部件を組み立てる Framework

LangGraph
= それらの部件を State 付き Workflow として制御する Framework
```

### 当前实现边界

- **LangGraph：已实现。** 当前明确用于 Task / KPI / Research / Report 的工作流编排。
- **LangChain：必须区分“架构职责”和“实际源码落地范围”。** 如果源码仅有依赖或兼容组件，而没有明确业务 import / 调用链，不得写成“全主链已由 LangChain 实现”。
- 文档、简历和面试材料应统一说明两者的**职责差异与协作方式**，同时保持与源码一致。


## 框架关系（当前）

```text
React
  ↓
FastAPI（HTTP Boundary · JWT/RBAC）
  ↓
Service Layer
  ├── Document / Import / Chunk
  ├── Retrieval / Internal RAG
  │      └── LangChain AI Components
  │          Prompt · Retriever · Context · Citation
  ├── Task / KPI Analysis
  │      └── LangGraph Agent Workflow
  │          State · Node · Edge · Conditional Route
  ├── AIAnalysis / ExecutiveReport
  │      └── LLMGateway（唯一 Provider 外呼）
  ├── Approval / ReportVersion
  └── Persistent Audit / Ledger
  ↓
Repository Interface
  ↓
PostgreSQL + pgvector（Current / 正式）

LangChain 与 LangGraph 的关系：
  LangChain = AI 组件组合
  LangGraph = 有状态 Workflow 编排
  LangGraph Node 可以调用 LangChain 的 Retriever / Prompt / LLM 组件
```

> **注意：** 当前主图必须同时体现 LangChain 与 LangGraph，但“是否已在业务主链全面落地”必须以源码调用链为准。

## 设计原则（V1.0）

| 层 | 原则 |
|---|---|
| FastAPI | HTTP 边界、DI、校验；不直连 LLM SDK |
| Service | 业务用例与状态机 |
| LLM Gateway | 收费 side-effect 唯一入口 |
| Repository | 隐藏 Postgres / InMemory |
| PostgreSQL + pgvector | **正式权威存储** |
| InMemory | unittest / test isolation adapter |
| Docker Compose | 可选部署与验收，不是唯一开发方式 |
