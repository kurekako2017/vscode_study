# 05_競合店舗調査

# 场景：Scenario01_Sales_Decline

共通シナリオ: 2026年6月 / 関東地区飲料分類売上下降分析

- 対象企業: 日本大型零售企業
- 正式システム: Enterprise Retail Intelligence Platform（ERIP）
- 部門: 经营企划部
- 業務背景: 関東地区の飲料販売が前年比・前月比ともに低下し、原因の切り分けと改善提案が必要
- 共通因果: 売上下降 → 在庫欠品 → 促販効果不振 → 競合値下げ → Analysis → 改善提案
- 共通商品: 炭酸飲料 / 茶飲料 / ミネラルウォーター / 無糖飲料
- 共通地域: 東京 / 神奈川 / 千葉 / 埼玉
- 共通結論の方向性: 供給改善、棚割り再設計、販促見直し、競合対策、KPIモニタリング

## 調査概要

関東地区の競合店を確認し、価格・販促・会員活動・広告・新商品投入の差を整理した。
売上低下の背景として、競合側が値下げと会員施策を同時に進めていたことが分かった。

## 競合店比較

| 競合店 | 価格 | 促販 | 会員活動 | 広告 | 新品 | 市場変化 |
|---|---|---|---|---|---|---|
| 競合A店（大型総合スーパー） | 炭酸 500ml 118円 / 茶 600ml 128円 / 水 500ml 88円 | 週末2本買うと10%引き | 会員アプリのスタンプ2倍 | 地域折込と店頭の同時訴求 | 新発売の無糖炭酸を先行投入 | 価格優位と新商品導入で若年層を獲得 |
| 競合B店（駅前スーパー） | 炭酸 500ml 123円 / 茶 600ml 132円 / 水 500ml 92円 | 平日夕方タイムセール | ポイント5倍デー | 駅構内ポスター中心 | PB茶飲料を強化 | 通勤客のついで買いに強い |
| 競合C店（ディスカウント） | 炭酸 500ml 109円 / 茶 600ml 119円 / 水 500ml 79円 | 箱買い割引 | 会員登録不要の特価 | SNSの短尺動画広告 | 大容量水と箱炭酸 | 価格競争を最も強く仕掛けている |
| 競合D店（ドラッグストア） | 炭酸 500ml 121円 / 茶 600ml 127円 / 水 500ml 90円 | 健康飲料セット割 | アプリ会員の限定クーポン | 医薬・健康と連動した販促 | 無糖茶と機能性飲料 | 健康志向の顧客を吸収している |

## 競争分析

- 価格面では競合C店が最も強く、箱買い需要を吸収している。
- 駅前立地の競合B店は通勤客の即買いに強い。
- 競合D店は健康志向と結びつけて無糖・機能性飲料を伸ばしている。
- 競合A店は売場の見栄えと新商品投入で若年層の関心を引いている。
- 当社は棚の空き時間が長く、価格比較以前に選択肢を失っている。

## 市場変化

1. 夏季入り前の段階で、すでに価格競争が激化している。
2. 会員アプリの利用が、単なる値引きではなく来店習慣づけに使われている。
3. 健康志向のカテゴリは、競合D店がうまく取り込んでいる。
4. 新商品導入の早さが、売場の鮮度に直結している。

## 競争対応の示唆

- 価格競争だけではなく、欠品ゼロと見つけやすさで差別化する。
- 会員施策は短期割引ではなく再来店導線を作る。
- 無糖飲料と茶飲料の売場を再設計する。
- 新商品は競合投入後ではなく、需要喚起の前に確保する。
- 広告は認知だけでなく、在庫連動で出し切る。

## 店舗別観測メモ
- 観測01: 競合A店では、週末の炭酸飲料売場に人が集まりやすい。
- 観測02: 競合B店では、夕方のタイムセールで客単価が上がる。
- 観測03: 競合C店では、箱買いのまとめ買いが目立つ。
- 観測04: 競合D店では、健康系飲料と一緒に軽い食品が売れている。
- 観測05: 関東全体で、飲料の買い方は「単品」から「用途別まとめ買い」に分かれている。
- 観測06: 当社はこの分岐に対して、棚面と価格での対応が弱かった。
- 観測07: 競合の先行対策は、分析だけでなく Approval を通じた施策判断が必要である。
- 観測08: 今後は、競合店調査を月次定点観測に変える。
- 観測09: 6月の競争環境は、7月の本格需要期の前哨戦と位置づける。
- 観測10: 結果として、在庫と販促の再設計が最優先である。
