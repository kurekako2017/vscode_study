# 03_販促キャンペーン結果

# Scenario01_Sales_Decline

共通シナリオ: 2026年6月 / 関東地区飲料分類売上下降分析

- 対象企業: 日本大型零售企業
- 正式システム: Enterprise Retail Intelligence Platform（ERIP）
- 部門: 经营企划部
- 業務背景: 関東地区の飲料販売が前年比・前月比ともに低下し、原因の切り分けと改善提案が必要
- 共通因果: 売上下降 → 在庫欠品 → 促販効果不振 → 競合値下げ → Analysis → 改善提案
- 共通商品: 炭酸飲料 / 茶飲料 / ミネラルウォーター / 無糖飲料
- 共通地域: 東京 / 神奈川 / 千葉 / 埼玉
- 共通結論の方向性: 供給改善、棚割り再設計、販促見直し、競合対策、KPIモニタリング

## 活動概要

- 活動期間: 2026-05-20 から 2026-06-15 まで
- 対象カテゴリ: 炭酸飲料 / 茶飲料 / ミネラルウォーター / 無糖飲料
- 活動目的: 夏季需要の先取りとまとめ買いの促進
- 想定成果: 売上 +6.0%、クーポン利用率 18.0%、SNS CTR 3.0%
- 実績結果: 売上 -1.8%、クーポン利用率 11.4%、SNS CTR 1.9%

## チャネル別実績

| チャネル | 実績 | 目標 | コメント |
|---|---|---|---|
| 店頭POP | 58店 | 目標比 84% | 棚前での訴求が弱く、実購買への転換が不足 |
| アプリクーポン | 配布 38,000件 / 利用率 11.4% | 目標 18.0% | 利用条件が厳しく、来店即時利用が少ない |
| SNS広告 | CTR 1.9% | 目標 3.0% | 若年層の反応はあるが広がりが限定的 |
| 館内サイネージ | 72画面 | 視認率は高いが購買導線に弱い | 特売訴求が単発で終わる |

## 実際の結果

- 店頭POPは設置店舗数こそ多いが、購買直前の訴求が足りなかった。
- クーポンは配布件数に対して利用率が低く、条件の複雑さが障害になった。
- SNS広告は若年層の反応はあるが、来店導線に結び付かなかった。
- 館内サイネージは視認されても、棚前の欠品で購入に至らないケースがあった。

## 問題分析

1. 促販の開始時点で在庫が十分ではなかった。
2. キャンペーン対象が広すぎて、メッセージがぼやけた。
3. クーポン条件が複雑で、初回利用の心理的障壁が高かった。
4. SNS広告は認知には寄与したが、購買の背中押しが弱い。
5. 競合店の値下げが同時期に起き、相対優位が失われた。

## 改善提案

- 販促前に在庫充足率 95% 以上を確認する。
- クーポンは「即時利用」「1画面完結」にする。
- 店頭POPは棚前 2m 圏内の視認性を優先する。
- SNSは認知よりも来店誘導リンクを重視する。
- 競合値下げに対しては、値引き以外の比較軸も作る。

## SNS と顧客反応

| 指標 | 数値 | 所見 |
|---|---:|---|
| 投稿数 | 2,450件 | 想定より少ない |
| ポジティブ比率 | 42% | 味の評価は悪くない |
| ネガティブ比率 | 20% | 価格と欠品への不満が中心 |
| 中立比率 | 38% | 関心はあるが購買動機が弱い |

## 施策別コメント
- コメント01: 初夏の水分補給というテーマ自体は需要と整合していた。
- コメント02: しかし棚に並んでいない時間があると、広告効果が失われる。
- コメント03: 炭酸飲料は「即飲み」需要を狙えるが、在庫連動が必須である。
- コメント04: 茶飲料は安定しているため、まとめ買い訴求に向く。
- コメント05: ミネラルウォーターは暑さが強い日に効果が出やすい。
- コメント06: 無糖飲料は健康志向の訴求を継続する価値がある。
- コメント07: クーポンは高頻度配布よりも、欠品しにくい商品に絞るべきである。
- コメント08: 店頭POPは視認性が高いコピーに改修する。
- コメント09: 6月末の総括として、販促だけでは売上反転は難しい。
- コメント10: 次回は在庫・売場・価格の3点同時改善が必要である。
