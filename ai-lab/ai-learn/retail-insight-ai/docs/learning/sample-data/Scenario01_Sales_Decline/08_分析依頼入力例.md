# 08_分析依頼入力例

# 场景：Scenario01_Sales_Decline

共通シナリオ: 2026年6月 / 関東地区飲料分類売上下降分析

- 対象企業: 日本大型零售企業
- 正式システム: Enterprise Retail Intelligence Platform（ERIP）
- 部門: 经营企划部
- 業務背景: 関東地区の飲料販売が前年比・前月比ともに低下し、原因の切り分けと改善提案が必要
- 共通因果: 売上下降 → 在庫欠品 → 促販効果不振 → 競合値下げ → Analysis → 改善提案
- 共通商品: 炭酸飲料 / 茶飲料 / ミネラルウォーター / 無糖飲料
- 共通地域: 東京 / 神奈川 / 千葉 / 埼玉
- 共通結論の方向性: 供給改善、棚割り再設計、販促見直し、競合対策、KPIモニタリング

## 利用方針

この文書は、RAG で見つかった事実をどのように Task に落とすかを学ぶための入力例である。
背景・入力・分析理由・期待報告・参照文書を揃えることで、Analysis が何を返すべきかを明確にする。

## 分析依頼一覧

### 业务用例：TASK-BIZ-001

- 背景: 関東地区飲料売上が 2026年6月に前年比 -7.8% となった。売上低下の主因を在庫・販促・競合の観点で整理してほしい。
- 入力: 関東地区飲料売上が 2026年6月に前年比 -7.8% となった。売上低下の主因を在庫・販促・競合の観点で整理してほしい。
- なぜ分析するか: なぜ売上が落ちたのかを経営会議で説明するため
- 期待分析内容: 因果の優先順位、主要課題、打ち手候補
- 期待報告: 売上要因 / 在庫要因 / 販促要因 / 競合要因 / 改善提案
- 関連 Documents: 01_関東地域飲料売上分析, 02_関東地域在庫レポート, 03_販促キャンペーン結果, 05_競合店舗調査, 06_KPI月次報告
