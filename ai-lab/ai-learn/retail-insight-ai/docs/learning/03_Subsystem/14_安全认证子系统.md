# 一、子系统定位

安全认证子系统（Security & Authentication Subsystem）负责整个系统的安全控制。

主要职责：

- 身份认证（Authentication）
- 权限控制（Authorization）
- API 安全访问
- RBAC（角色权限）
- Audit Log（审计日志）

一句话：

> **Authentication 决定"你是谁"，Authorization 决定"你能做什么"。**

# 十七、面试回答（中文）⭐⭐

如果面试官问：

> 为什么安全认证要独立成子系统？

可以回答：

> Retail Insight AI 将身份认证、权限控制和审计日志统一封装到安全认证子系统中。Authentication 用于验证用户身份，Authorization 基于 RBAC 判断用户是否具有接口访问权限，Audit Log 记录关键操作，实现企业级安全治理。业务模块无需重复实现安全逻辑，提高了系统的一致性和可维护性。

---

# 十八、面试回答（日语）⭐⭐

面接官：

> セキュリティ機能を独立したサブシステムにしている理由は何ですか。

回答例：

> Retail Insight AI では、認証（Authentication）、認可（Authorization）、監査ログ（Audit Log）をセキュリティサブシステムとして分離しています。認証では利用者本人であることを確認し、認可では RBAC に基づいて API の実行権限を判断します。また、重要な操作は監査ログとして記録し、企業システムに求められるセキュリティとコンプライアンスを実現しています。これにより、各業務モジュールはセキュリティ処理を個別に実装する必要がなくなり、保守性と拡張性が向上しています。
