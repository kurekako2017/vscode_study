# 一、子系统定位

文档检索子系统（Document Retrieval Subsystem）负责整个企业知识库管理。

主要职责：

- 上传文档
- 删除文档
- 查询文档
- 保存文档
- 为 AI Workflow 提供知识来源

一句话：

> **Documents 管理知识，Workflow 使用知识。**

# 十七、面试回答

如果面试官问：

> 文档检索为什么要独立成子系统？

可以回答：

> Retail Insight AI 将文档管理、数据存储和 AI Workflow 解耦。Documents API 负责知识管理，Repository 负责持久化，Research Node 在 Workflow 中调用文档检索，为 LLM 提供上下文。当前项目已具备 Internal Document Retrieval 能力，并预留了 LangChain、Embedding、pgvector、Hybrid Search 等企业级 RAG 扩展点。
