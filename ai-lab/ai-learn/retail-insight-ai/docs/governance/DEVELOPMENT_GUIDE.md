# 开发指南

## Learning Trace / Learning Experience

涉及 Learning Trace、Console Log、Source Chain、学习体验、源码调用链展示、学习文档结构等修改，属于 Learning Experience Change。

此类修改必须：

1. 提交修改方案
2. 说明影响范围
3. 经确认后实施

未经确认，不允许自行调整日志格式、调用链展示方式或学习文档结构。
